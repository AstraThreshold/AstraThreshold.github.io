# WoooLAB web brand assets

Derived from the supplied `wooolab-logo/logo/ver3_logo_only_mono_hd.png` (5920 × 2560). Original files are unchanged.

- `wooolab-dark.svg/png`: dark foreground for light backgrounds.
- `wooolab-light.svg/png`: light foreground for dark backgrounds.
- `wooolab-original.png`: cropped original white logo with original black extrusion.
- `favicon.svg`, `favicon.ico`, and `favicon-{size}.png`: the supplied leading `>` and trailing `_`, cropped and joined with a one-cell gap. The ICO contains 16, 32, 48, and 64 px sizes.

All contours come from original pixels. SVGs trace exact native 80 px cell runs; no font glyph or generated logo substitutes are used. Monochrome wordmarks isolate the white glyph foreground and remove the original black extrusion. See `provenance.json` for exact coordinates.
