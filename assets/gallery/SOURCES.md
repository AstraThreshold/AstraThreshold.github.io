# Gallery sources

All photographs were supplied by the site owner in `wooolab-logo/banner/`.
Embedded original images were extracted as bytes from the PSD smart objects. Where no embedded original existed, the individual pixel layer was exported without the banner overlays.
Web copies preserve the source composition and color, apply EXIF orientation, convert tagged profiles to sRGB, and strip metadata. They are downscaled only, never enlarged. No retouching or generated content was used.
Full views are limited to a 2000 px long edge; thumbnails to 720 px. Both are WebP. The webpage crops thumbnails with CSS; clicking opens the uncropped web copy.
