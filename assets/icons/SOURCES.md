# Contact icons

Retrieved on 2026-11-12 and bundled locally as monochrome, transparent SVGs.

| Icon | Source | License |
| --- | --- | --- |
| GitHub | [GitHub Primer Octicons, mark-github-16.svg](https://github.com/primer/octicons/blob/main/icons/mark-github-16.svg) | MIT, `LICENSE-octicons.txt` |
| Bilibili | [Simple Icons, bilibili.svg](https://github.com/simple-icons/simple-icons/blob/develop/icons/bilibili.svg) | CC0, `LICENSE-simple-icons.txt` |
| Email | [Heroicons, envelope.svg](https://github.com/tailwindlabs/heroicons/blob/master/src/24/solid/envelope.svg) | MIT, `LICENSE-heroicons.txt` |

The source SVG paths are unchanged. CSS uses the SVGs as alpha masks and fills
them with the page's current text color. No icon fonts, raster copies, background
tiles, remote asset services, or external SVG references are used. The links
retain accessible names and native hover titles; email opens `mailto:fir@live.it`.
